## 功能特性

- 按书名批量下载小说，自动识别章节与正文
- **跨发行版自动适配**：Arch / Debian系 / Fedora系 / SUSE / Gentoo / Void / Alpine，按各家包管理自动安装依赖，未知发行版会用pip

## 快速开始

```bash
chmod +x Book-Downloader.sh
./Book-Downloader.sh [书名]
```

首次运行会自动检测并安装所需依赖（需要 root/sudo 权限）。
